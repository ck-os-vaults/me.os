# Starter.OS origin and optional updates

This private system belongs to its owner. Starter.OS supplied its starting files;
it is not the system's identity or an authority over future owner decisions.

Read this reference only when origin, licensing, or an update is relevant. It is
not part of routine startup. `release.json` records source and adoption evidence;
`license.md` retains attribution. Baselines support comparisons, not edit restrictions.

All installed instructions, manuals, workflows, and maps may be maintained under
the owner's authority. Existing customizations need no fork registration. New
personal skills use `owner-skills.md`; both skill registries remain owner-maintained.

For an optional update, inspect the current [public source](https://github.com/ck-os-vaults/starter-os-public)
and its update guide. Agree on useful improvements and exact adaptations, preserve
the owner's meaning, and verify recovery before applying the agreed plan. Declining
an update does not invalidate the system. Older updaters cannot read the 3.2 adoption
record and must not be used to downgrade it.
