# Scripts

Small checks that help keep this template working. Your agent can run them; you do not need to edit them.

| File | Purpose |
|---|---|
| `validate.py` | Checks required files, links, dates, and leftover template details |
| `test_template.py` | Checks the template using a fictional personalized workspace |

These scripts maintain the public template and are not copied into your personal workspace during setup.
